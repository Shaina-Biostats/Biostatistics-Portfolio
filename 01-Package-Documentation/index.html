statwise R Package

Installation & Package Access

Information about installing statwise, accessing its documentation, and exploring publicly available examples.

PACKAGE OVERVIEW

About statwise

statwise is an R package developed to support reproducible biostatistical workflows through reusable functions for data cleaning, descriptive summaries, visualization, SAS integration, and HTML/PDF reporting.

Repository Status: Private

The statwise source repository is currently private. Installation requires authorized GitHub access and authentication. Public demonstrations and documentation are available through this portfolio.

INSTALLATION

Install from GitHub

Users with authorized repository access can install the development version of statwise directly from GitHub.

Step 1 — Install remotes

install.packages("remotes")

Step 2 — Install statwise

remotes::install_github(
  "Shaina-Biostats/statwise",
  force = TRUE,
  upgrade = "never"
)

Step 3 — Load the package

library(statwise)
Access Requirement

Because the repository is private, the installation will only succeed for users with the appropriate GitHub permissions and authentication.

DOCUMENTATION

Getting Help

Once the package is installed, view its available functions and documentation directly in R. 

help(package = "statwise")

For help with a specific function:

?statwise_colors
?statwise_palettes
