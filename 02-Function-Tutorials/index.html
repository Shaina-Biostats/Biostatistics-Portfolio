Featured R Package

statwise

Reusable R tools for biostatistical analysis, data preparation, descriptive statistics, visualization, SAS integration, and professional HTML/PDF reporting.

Explore Features View Report Examples Back to Portfolio

Core Package Features

A collection of reusable functions designed to make statistical workflows more consistent and reproducible.

DATA PREPARATION

Data Cleaning & Quality Checks

Standardize variable names and character values, inspect missing data, and remove attributes that interfere with comparisons.

clean_data(), check_missing(), remove_attributes()

DESCRIPTIVE STATISTICS

Summary Tables

Generate standardized descriptive summaries and transform them into presentation-ready tables for statistical reports.

summarize_variables(), build_descriptive_table()

VISUALIZATION

Consistent Statistical Figures

Create figures with a consistent ggplot2 theme, custom colors, and categorical, sequential, or diverging palettes.

theme_statwise(), statwise_colors(), statwise_palettes()

R + SAS

SAS Integration

Discover and inspect SAS macros, execute them from R, pass R datasets to SAS, and retrieve supported output datasets. A local SAS installation is required.

list_sas_macros(), sas_macro_help(), run_sas_macro()

INTERACTIVE REPORTING

Interactive HTML Components

Build HTML reports with selectable themes, radio-button content panels, and collapsible sections using R functions. The selectors support plots, tables, and interactive content.

theme_selector(), radio_selector_1(), radio_selector_2(), collapsible_section()

Statistical Visualization

library(ggplot2)
library(statwise)

ggplot(mtcars, aes(wt, mpg)) +
  geom_point(
    color = statwise_colors("medium_blue")
  ) +
  theme_statwise()

Apply consistent formatting and a package-defined color.

Descriptive Summary

summary_long <- summarize_variables(
  data = survival::lung,
  variables = c("age", "ph.ecog"),
  digits = 1
)

summary_table <- build_descriptive_table(
  long_summary_data = summary_long
)

Create reusable descriptive summaries and reporting tables.
