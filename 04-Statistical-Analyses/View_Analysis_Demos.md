# Statistical Analysis Demos

Explore two reproducible statistical analyses developed in R using the `statwise` package. Each analysis is available as an HTML report, a PDF report, and R Markdown source files.

## 1. Lung Cancer Survival Analysis

**Methods:** Descriptive statistics, Kaplan–Meier survival analysis, log-rank test, and Cox proportional hazards regression.

This analysis examines survival outcomes among patients with advanced lung cancer, comparing participants across two age groups.

## 2. Craniofacial Growth Longitudinal Analysis

**Methods:** Linear mixed-effects models, likelihood ratio tests, interaction analysis, predicted trajectories, and model diagnostics.

This analysis evaluates changes in craniofacial distance over time and investigates differences in growth trajectories between boys and girls.
