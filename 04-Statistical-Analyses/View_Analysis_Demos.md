# Statistical Analysis Demos

Explore two reproducible statistical analyses developed in R using the `statwise` package. Each analysis includes HTML and PDF reports, along with R Markdown source files.

## 1. Lung Cancer Survival Analysis

**Methods:** Descriptive statistics, Kaplan–Meier survival analysis, log-rank test, and Cox proportional hazards regression.

This analysis examines survival outcomes among patients with advanced lung cancer.

## 2. Craniofacial Growth Longitudinal Analysis

**Methods:** Linear mixed-effects models, interaction analysis, predicted trajectories, and model diagnostics.
