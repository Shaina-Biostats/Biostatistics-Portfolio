## Featured Project: statwise

### An R Package for Smarter Statistical Workflows

**statwise** is an R package I developed to simplify statistical analyses, bridge R and SAS, automate routine tasks, and create professional, customizable, and interactive statistical reports.

The package combines statistical utilities, cross-platform analytical workflows, and reusable reporting components to help analysts work more efficiently.

### Key Features

#### 1. R–SAS Integration: One Workflow, Two Powerful Languages

**Run SAS analyses directly from R — without switching between applications.**

statwise enables analysts to integrate existing SAS macros and statistical procedures into R-based workflows, supporting more efficient and reproducible statistical analyses.

- Execute SAS macros directly from R.
- Pass datasets and analysis parameters to SAS macros.
- Reuse existing SAS analytical procedures within R workflows.
- Streamline statistical programming across R and SAS.
- Reduce repetitive tasks and manual switching between applications.

#### 2. Interactive HTML Reporting — No JavaScript or CSS Required

**Build interactive, customizable HTML reports using R functions alone.**

statwise provides reusable reporting components that allow analysts to create interactive and visually consistent HTML reports without manually writing JavaScript or CSS.

- **Radio button selectors:** Organize and switch between report content or visualizations.
- **Theme selectors:** Change report appearance using predefined themes.
- **Collapsible sections:** Expand or hide content for cleaner report navigation.
- **Tab-based layouts:** Organize analyses and results into accessible sections.
- **Report navigation:** Create structured reports with convenient navigation elements.
- **Reusable components:** Add interactive features directly through R functions.

These features simplify report development while maintaining flexibility, consistency, and professional presentation.

#### 3. Statistical Utilities & Workflow Automation

**Spend less time on repetitive programming and more time on statistical analysis.**

- Data cleaning and preparation utilities
- Missing-data checks and summaries
- Automated descriptive statistics
- Customizable summary tables
- Consistent statistical visualization themes
- Reusable functions for reproducible reporting
