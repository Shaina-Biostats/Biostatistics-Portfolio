Built for Biostatistical Analysis and Reporting

statwise is my R package providing utilities for data cleaning, descriptive summary tables, visualization, SAS integration, and professional HTML/PDF reporting.

  • Custom ggplot2 themes, colors, and palettes
  • Interactive HTML report components and theme selection
  • HTML and PDF report starter templates
  • Descriptive summaries and presentation-ready tables
  • Running SAS macros directly from R
